# 舞镜 交接文档 · 2026-07-31

## 今日完成

### 卡片系统
- 三张 PNG 卡片自动生成：八拍卡v3.png / 镜面卡v3.png / 记忆卡v3.png
- 用户上传视频 → decompose 完成 → gen_cards.py 自动运行 → 卡片可下载
- cards/ 目录结构：
  - gen_cards.py（主入口，修复了 `__file__` bug）
  - card_engine.py（共用字体/颜色常量）
  - 八拍卡_v3.py / 镜面卡_v3.py / 记忆卡_v3.py
  - 字体：服务器用 NotoSansCJK，本机用 STHeiti

### Whisper 歌词对齐
- 用户填歌曲名/首句/末句后，服务器 Whisper base 模型转录音频
- 按时间窗口 [t0,t1] 匹配最重叠的转录段，赋给 phrase["lyric"]
- 失败 fallback：DeepSeek API 均匀分配歌词到各 phrase
- 代码：`auto_decompose.py` → `whisper_align_lyrics()` + `_assign_lyrics_deepseek()`

### 跟练模式（practice mode）
- 每个 phrase 行末有「⏯ 跟练」按钮
- 全屏弹层：上方慢速视频（_slow.mp4） + 下方帧图横滚
- 左右导航按钮 / ← → 键盘 / Escape 关闭
- 打开时 body scroll 锁定，关闭时恢复
- 视频出错时显示"慢速视频生成中，稍后可用"提示

### 首页 Demo
- 三个真实舞蹈固定展示（点击进入已完成拆解结果）：
  - 虞兮叹：vid_1679971642（9 phrases）
  - 孽：vid_2130688639（8 phrases，双人）
  - 春满园：vid_563626483（6 phrases）

### 拖拽上传
- 上传区支持 drag & drop（dragover / dragleave / drop 事件）
- `dcDropFile()` 函数处理拖入文件，与 click 上传共用后续流程

### 屏幕适配
- `_dcShow()` 里去掉 paddingLeft/paddingRight，动作帧不再溢出屏幕边缘

## 服务器架构

| 项目 | 值 |
|---|---|
| 服务 | systemd → wujing-api → FastAPI port 3006 |
| 反代 | Caddy → wujing.mylumee.app |
| 静态文件 | `/www/wujing-api/static/design-upgrade.html` |
| 数据根目录 | `/www/wujing-api/data/{did}/` |
| 卡片脚本 | `/www/wujing-api/cards/` |

数据目录结构（每个 did）：
```
/www/wujing-api/data/{did}/
  decompose.json          ← status/phrases/lyric/key 等
  frames/
    p{i}_{f}.jpg          ← 帧图（f=0..strip-1）
  clips/
    p{i}.mp4              ← 正常速度片段
    p{i}_slow.mp4         ← 0.5x 慢动作片段
  八拍卡v3.png
  镜面卡v3.png
  记忆卡v3.png
```
