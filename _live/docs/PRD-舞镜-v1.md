## 一、产品定位与核心价值

### 1.1 一句话定位

**别人教你做什么，我们教你怎么永远记住。**

用AI把每支舞蹈提炼成「口诀」——3字心法刻进脑子，不靠重复练习，靠记忆结构。

### 1.2 目标用户

| 用户类型 | 描述 | 核心需求 |
|----------|------|---------|
| **舞蹈爱好者** | 18-35岁，上过几节课但经常忘、放弃 | 学了不忘，坚持下去 |
| **舞蹈老师** | 有学员但备课耗时，学员课后忘动作 | 提效备课，学员留存 |
| **KOL学舞者** | 想学热门舞蹈发小红书/抖音涨粉 | 快速上手，出内容 |

### 1.3 核心问题

用户现在学舞的路径：

```
看视频 → 跟着跳 → 忘了 → 倒回去 → 再跳 → 又忘
（重复50次，靠肌肉记忆硬压进去，一个月学1-2首）
```

**根本痛点**：所有教程只告诉你「做什么」，没有人告诉你「怎么记住」。没有记忆钩子，动作就像水，流过去就没了。

### 1.4 解决方案

**口诀记忆法**：将每个舞蹈动作提炼为3-4字心法

```
例：《执笔》第一句
传统描述：右手执笔姿势，缓缓遮面，推手向前展开，收回胸前
口诀：「遮·推·收」
效果：闭眼默念3字，动作自然还原
```

**双通道记忆**：慢放视频（眼睛看）+ TTS朗读口诀（耳朵听）→ 同步输入，记忆效率翻倍

**结果对比**：
- 传统方式：1个月练1-2首
- 舞镜方式：1个月练30首（口诀记住即掌握，MediaPipe纠正细节）

### 1.5 竞品对比

| 竞品 | 核心缺陷 | 舞镜优势 |
|------|---------|---------|
| 抖音「学一学」 | 无结构拆解，跟着视频盲跟 | AI逐句拆解 + 口诀 |
| 小红书舞蹈教程 | 碎片笔记，无练习路径 | 完整学习闭环 |
| YouTube教程 | 无中文，无口诀，无卡片下载 | 中英双语 + 可下载卡片 |
| 街舞App（WeSing等） | 只覆盖街舞，无口诀体系 | 10大舞种全覆盖 |
| 线下舞蹈课 | 老师说一遍就过，课后无辅助 | 课前预习口诀，课上不慌 |

## 二、核心功能模块

### 模块1：口诀拆解引擎

**输入**：舞蹈视频文件 或 YouTube/抖音链接

**输出**：逐句拆解数据包，每句包含：

```json
{
  "i": 1,
  "name": "起手遮面",
  "t0": 4.2,
  "t1": 8.6,
  "action": "右手执笔姿势缓缓遮面，推手向前展开，收回胸前",
  "action_en": "Right hand rises to cover face, push forward, pull back to chest",
  "kou": "遮·推·收",
  "key": "遮",
  "lyric": "执笔画你 眉间一点朱砂痣"
}
```

**质量标准（每条口诀必须通过）**：
- 简短：3-4个汉字，用「·」分隔
- 可发音：念出来顺口，不拗口
- 可还原：听到口诀 → 脑子里能浮现出动作
- 诗意：有韵律感，不是技术描述
- **人工审核**：AI生成后必须由人工确认通过

**好口诀 vs 坏口诀**：

| 好口诀 | 坏口诀（不能用）|
|--------|----------------|
| `遮·推·收` | `向右转身抬起右手` |
| `绕·落·仰` | `Step1右脚前` |
| `推·绕·弹` | `Hip circle right` |

**技术实现**：
- Whisper（本地）转录歌词 → 时间戳对齐
- DeepSeek API 生成口诀（省 Claude 配额）
- 人工审核界面（管理后台）

### 模块2：六件套产出包

**铁律：每首舞六件套全部完成才能上线，缺一不可。**

| 件 | 产出物 | 说明 |
|----|--------|------|
| 1 | **慢放视频** | 0.5x速度，ffmpeg生成，带口诀字幕覆盖 |
| 2 | **八拍卡 PNG** | 帧图8格+口诀+歌词，1100px宽，可下载 |
| 3 | **镜面卡 PNG** | 帧图左右镜像翻转，不用换算左右 |
| 4 | **记忆卡 PNG** | 谐音/联想记忆法，帮助长期记忆 |
| 5 | **TTS朗读音频** | 慢放视频播放时同步念出口诀，无需录制 |
| 6 | **AI老师预习文字** | 课前阅读：这句要注意什么、口诀怎么用 |

**TTS朗读实现**：
- 使用系统TTS或免费TTS API（阿里云TTS免费额度）
- 合成格式：`[停顿0.5s] 第一句 [停顿0.3s] 遮 [0.2s] 推 [0.2s] 收 [停顿1s]`
- 与慢放视频时间轴对齐，ffmpeg合并为最终视频

### 模块4：学习体验

**每日一首**：基于日期推荐（不随机），所有用户同一天学同一首，制造社群感

**完整练习流程**：
1. 预习：读 AI老师预习文字 + 看口诀卡（课前3分钟）
2. 观看：慢放视频 + 耳机听TTS朗读口诀
3. 跟练：分句练习，单句循环，速度可调（0.3x / 0.5x / 0.7x）
4. 镜像模式：镜像翻转，不用换算左右
5. 打卡：完成今日练习 → 获得印章

**印章系统**：
- 每日完成练习 → 1枚印章
- 连续7天 → 特殊成就徽章
- localStorage存储：`wujing_stamps`
- 印章界面：日历格，已打√，今日高亮

**进度追踪**：
- 每首舞：已学N句 / 共N句（进度条）
- 总进度：已学X首 / 库中Y首
- 学习时长记录

### 模块5：MediaPipe 姿势评估

**输入**：用户用前置摄像头拍自己跟练

**处理**：
- MediaPipe Pose 提取用户骨架（33个关键点）
- 与标准动作骨架对比（从原视频提取）
- 计算关节角度偏差

**输出**：
- 实时反馈：「左臂抬高15°」「膝盖再弯一些」
- 评分：0-100分（和「标准」的相似度）
- 每日进步曲线（历史评分图）

**隐私**：摄像头数据本地处理，不上传服务器

| 口诀生成 | DeepSeek API（省Claude配额） | ✅ 已集成 |

| 存储 | 本地 /www/wujing-api/data/（短期） | 需迁移OSS |

### 4.2 批量处理流水线

```
yt-dlp下载(720p) 
  → ffmpeg提帧(每0.2s一帧)
  → Whisper转录歌词+时间戳
  → DeepSeek生成口诀+动作描述
  → 人工审核口诀
  → PIL生成3张卡片PNG
  → ffmpeg生成慢放视频(0.5x)
  → TTS生成口诀朗读音频
  → ffmpeg合并慢放+字幕+TTS音频
  → 上传阿里云OSS
  → 删除本地原视频
  → 更新library_index.json
  → 上线
```

每首处理时间：约10-15分钟（含下载）
批量节奏：逐首完整处理，质量验收通过再处理下一首

### 4.3 存储规划

| 内容 | 单首大小 | 1000首总量 | 方案 |
|------|---------|----------|------|
| 帧图 (JPG) | ~50MB | ~50GB | 阿里云OSS |
| 卡片PNG | ~10MB | ~10GB | 阿里云OSS |
| 慢放视频(含TTS) | ~200MB | ~200GB | 阿里云OSS |
| decompose.json | <1MB | <1GB | 服务器本地 |
| **合计** | **~260MB** | **~260GB** | **OSS ~¥26/月** |

**CDN加速**：OSS绑定CDN，用户访问帧图/卡片延迟 < 100ms
