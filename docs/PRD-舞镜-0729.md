# 舞镜 PRD（0729 定稿·CEO 存档）

> AI 舞蹈/健身拆解教练。上传一段视频 → AI 当老师给你拆解、打分、指导。
> 真生产：wujing.mylumee.app（HK 服务器 47.242.80.65:3006，后端 `/www/wujing-api` FastAPI）

---

## 一、核心价值
学舞/健身最痛：**记不住动作、不知道自己做得对不对、没老师纠正**。
舞镜 = 上传视频，1 分钟出「拆解 + 打分 + 老师指导」，跟着卡片几天记住整支舞/练对动作。

## 二、核心流程（上传 → 产出）
用户挑参考（老师舞/标准动作）→ 上传自己的视频 → 后台分析 → 出：
1. **八拍图** — 整支舞拆成 N 个八拍，每拍动作要点 + 口诀 ✅已上线
2. **慢播视频** — 每个问题点自动慢动作对比 ✅已有
3. **评分** — 豆包 vision 看画面对比老师，0-100 分 + 各维度 ✅已上线(真AI)
4. **记忆图** — 口诀串联 + 记忆技巧 ✅已上线
5. **故事图** — 情感叙事，帮跳出感觉/眼神 ✅已上线
6. **老师点评指导** — 温柔专业点评 + 3 条针对性纠正建议 ✅已上线

## 五、舞蹈知识库（让点评更专业）
注入 vision/DeepSeek 的 prompt，做术语字典。示例条目：
- **云手**：双手在体前画圆，一上一下交替翻掌，重心随手左右移，眼随手走。要点：手腕引领、肩沉、圆活不僵。
- **兰花指**：中指与拇指相近，其余三指自然翘起，古典舞手型，指尖有延伸。
- **水袖**：抛/收/绕，力从腰起达指尖，袖随身动。
- （知识库由 DeepSeek/Ollama 批量生成扩充，存 `data/dance_kb.json`）
