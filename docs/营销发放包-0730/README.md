3. **不越合规红线**：禁"瘦身/塑形/矫正体态/治疗"承诺；禁"X天学会/一定跳好"；前后对比标"个人案例，非普遍结果"。

6. **生图**：卡片prompt必须先给Karen确认，再本机ComfyUI生成（零API费）。真人底图生成后需过8分门槛才用。
