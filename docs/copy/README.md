## 平台发帖指南

### 小红书
- 发帖时间：**周二/四/六 19:00-21:00**
- 配2-3张图（参考每套文案末尾配图建议）
- 先从痛点组（01）和情感组（10）冷启动
- 带话题 #舞镜 #AI舞蹈 #学舞

### TikTok / 抖音
- 发帖时间：**每天 19:00-22:00**
- 竖版视频+文案字幕效果最佳
- 优先使用裂变组（07）引评论互动

### Instagram
- 英文文案面向：海外华人 + 中国舞爱好者 + K-pop翻跳社区
- Reels优先，Carousel次之
- 主要 hashtag 池：#dancemirror #chinesedance #kpopdance #AIcoach #舞镜

### Reddit
- 发在：r/chinesedance / r/kpop / r/learnese / r/dance
- 真实分享语气，不要硬推广告
- 点赞互动后再评论引流
