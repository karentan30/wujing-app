比如：

Been doing a complete analysis of this choreography using WuJing's frame capture system. Sharing notes in case anyone else is working on this piece.

**Section 1 (beats 1-32) — Cloud hand sequence:**
There are four cloud hand phrases and they look identical at playback speed. They're not — each one has a subtly different closing hand position that transitions into the next opening. If you're drilling all four as the same phrase, you'll have persistent timing issues at the transitions. Check frames 7-8 of each phrase for the transition hand position.

**Section 2 (beats 33-64) — The turn-and-look:**
This is the technical peak of the piece. Left sleeve extension with simultaneous right head rotation — body and gaze in opposition. The frame analysis shows the torso rotation (~15 degrees left) and head orientation (~45 degrees right) happen on the same beat, not in sequence. Most learners execute them sequentially, which kills the aesthetic tension the movement is built around.

**Section 3 (beats 65-96) — Footwork:**
High-density footwork with a repeating 4-count pattern. The rhythm cue "step-step-tap-hold" works well. Once internalized, the footwork almost runs itself.

**Section 4 (beats 97-128) — Final section:**
This section's difficulty is performative rather than technical. The choreography implies a sense of elevated perspective / looking into distance. That quality of presence has to come from inside the movement, not from technique. Technically it's the easiest section; artistically it's the most demanding.

很多人问我学舞的流程，今天完整写一遍，这套方法我用了大概半年，现在学新舞的速度是以前的三倍。

**第一阶段：「看懂」（第1天）**

不练，只读八拍卡。

把整支舞的所有八拍卡翻一遍，目标是：读完之后能在脑子里想象整段。不用记住细节，只要大概知道有哪些动作、大概在哪里。

这个阶段很多人会跳过，直接开始练。但是「没看懂就练」等于「没看书就做题」——你在记的是错误的印象。

**第二阶段：「拆开练」（第2-3天）**

每次只练一组八拍。

对着关键帧截图，把自己的动作调整到和截图一致。这个过程不用音乐，慢慢来。一组练到「对照截图基本一致」再练下一组。

口诀在这个阶段开始用——每组八拍对应一个口诀名称，练的时候嘴里念口诀，形成肌肉记忆和语言记忆的双重绑定。

**第三阶段：「连起来」（第4天）**

把所有组连起来，加音乐。

第一遍一定很糟糕，不要在意。目的是检查哪些衔接点还没打通，然后重点练那几个连接处。

录视频，对照原版，找差距。

这个阶段不再用八拍卡做参考，改用自己的视频和原版视频对比。用慢动作找具体的不同，回到对应的八拍卡去理解为什么。

**A systematic method for learning choreography — refined over 6 months**

I've gone through probably 20 different choreographies using WuJing's frame analysis tools over the past 6 months. Here's the workflow I've landed on. Sharing because the "watch and imitate" default approach is genuinely inefficient and I wish someone had told me this earlier.

**Phase 1: Comprehension (Day 1, no movement)**

Read all 8-beat cards before practicing anything. Goal is mental model, not memorization. You want to understand the shape of the piece — what movements exist, roughly where they occur — before your body starts forming habits.

Skipping this phase means your first practice reps are building impressions of a choreography you don't understand. Those impressions are hard to overwrite.

**Phase 2: Isolated phrase work (Days 2-3)**

One 8-beat phrase per session. No music. Reference the frame captures to check position accuracy. Advance only when the phrase matches the reference at each beat. Use the memory cue names while practicing — this creates dual encoding (motor memory linked to verbal label) which improves retrieval under pressure.

**Phase 3: Connection (Day 4)**

Full run-through with music. First connection attempt will be messy — use it diagnostically to find which phrase transitions break down. Those are the targets for additional work.

**Phase 4: Refinement loop (Days 5-7)**

Record yourself, compare to the source. Use slowdown for specific position differences. Return to the relevant 8-beat card when something is off. Iterate.

Results: routinely learning 1-2 minutes of choreography to performance level in 7-10 days. Previously this took 3-4 weeks for equivalent material.
