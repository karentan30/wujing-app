# 舞镜 · Demo 录屏脚本(60s · 导演版)

> 手机/电脑开 `wujing.mylumee.app`(或 `www.mylumee.app/dance/`)· 系统自带录屏 · 竖屏 1080×1920
> 定位:成人爱好者 + 艺考生。核心卖点:**不是打分,是逐帧量到度 + 记忆法 + 专家评审团**。
> 拍前准备:先用一支真舞跑好结果(或用现成《关山酒》/「孽」),录制时直接进结果页,别录30秒加载。

---

### 镜1 · 0–6s｜钩子(首页)
- **画面**:首页——银色底,大字「跳得像不像?AI 逐帧量给你看」+ ¥9.9 价格卡 + 上传按钮。
- **运镜**:静止定格 1s → 缓慢推近到「量给你看」四个字。
- **字幕(大)**:你跳的舞,到底差在哪?
- **旁白**:别人只会说"再练练",舞镜直接量给你看。

### 镜2 · 6–14s｜上传(降门槛)
- **画面**:点「上传你的舞」→ 选一段自己跳的视频 → 进度环「逐帧测量关节角度 · 还需18s」。
- **运镜**:跟随手指点击 → 停留在进度环转动 2s(给科技感)。
- **字幕**:上传一段 · AI 逐帧拆解
- **旁白**:传一段你自己跳的,免登录。

### 镜3 · 14–26s｜⭐量到度(最强钩子·给足停留)
- **画面**:结果出来 → 滑到八拍卡 → 点开「📐 AI 逐帧实测角度」,展开显示 左肘167° 右肩105° 躯干10°…
- **运镜**:慢滑 → **定格在角度数字上 2s**,轻微放大。
- **字幕(重点)**:不是打分,是量到度 —— 左肘 167°,该 180°
- **旁白**:每个关节差几度,清清楚楚。别人抄不了。

### 镜4 · 26–38s｜专家评审团(专业感)
- **画面**:滑到「专家评审团 · AI 多视角」→ 📐测量区 + 🎭观察区(舞蹈老师 / 艺考评委 / 演出导演 / 身韵)。
- **运镜**:逐条慢滑,**在「艺考评委:接近联考中等,优先补…」和「身韵:…建议配合提沉呼吸」各停 1.5s**。
- **字幕**:舞蹈老师 + 艺考评委 + 演出导演,一次全给你
- **旁白**:艺考差什么、身韵怎么补,像真评委那样说清。

### 镜5 · 38–48s｜慢放镜像跟练 + 记忆法
- **画面**:点一段「慢放 0.5× · 🪞镜像」跟练视频(画面底部叠口诀浮层「开—定—靠—立」)→ 滑到「记忆卡·速记攻略」(★重复段"学一个就行" / 高低点路标)。
- **运镜**:视频播 2s → 滑到速记攻略停 2s。
- **字幕**:慢放镜像跟着练 · 口诀帮你记全曲
- **旁白**:对着镜像慢慢跟,重复动作学一个就够。

### 镜6 · 48–56s｜故事卡(情感差异化)
- **画面**:滑到「故事卡 · 关山酒·醉舞」+ 押韵串记口诀。
- **运镜**:慢滑,停在故事正文 2s。
- **字幕**:整支舞编成一个故事 · 记情绪不记招式
- **旁白**:记不住动作?把它跳成一个故事。

### 镜7 · 56–60s｜收尾(转化)
- **画面**:回顶部,logo「舞镜 · Dance Mirror」定格 + 一行「任意舞拆成能跟练的卡 · ¥9.9/支」。
- **运镜**:定格,轻微呼吸放大。
- **字幕(大)**:舞镜 · 一支只要一杯奶茶钱
- **旁白**:舞镜。你想学的舞,逐句拆开。

## 出片铁律(按Karen规范)
- 真实录屏·不摆拍·不磨皮·手指点击真实。
- 字幕:大字幕(钩子/量到度/收尾)用衬线大号,其余小字幕。旁白可后期配音或纯字幕。
- 节奏:镜3(量到度)是命门,停留最久;加载别录满。
- 合规:不出现模型名(已清)· 结尾可加极小字"AI生成·仅供训练参考"。
- 发小红书:封面用镜3的"量到度"定格(左肘167°→180°)最抓艺考生。
