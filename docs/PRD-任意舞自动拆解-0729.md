# 舞镜 · 任意舞自动拆解 + AI角度教练 PRD（0730 锁定版）

> **一句话**：用户上传任意一支舞 → AI 自动拆成能跟练的八拍卡 + 故事卡 + 记忆卡，并用 **MediaPipe 测量真实关节角度**给精准点评。练习时开摄像头**实时看角度**。
> **护城河/付费墙**：客观测量的角度纠错（"左肘68°→需170°"），别人抄不了 = 能收费。
> **裂变**：所有产物一键分享（带水印）；不付费=下载带走。**同一套姿态技术复用到健身版。**

生产：`wujing.mylumee.app`（HK 47.242.80.65:3006）· 本地副本 `~/projects/舞镜/_live/`（scp+md5）
主服务 numpy2 与 mediapipe 冲突 → mediapipe 装**独立 mpvenv**，pose 走子进程（已验证安全）。
