```python
# 改前（错误顺序）
@app.post("/api/pay/wechat/create")
async def wechat_create(body: PayRequest):  # body校验先
    user = get_current_user(...)  # auth在后

# 改后（正确顺序）
from fastapi import Header

@app.post("/api/pay/wechat/create")
async def wechat_create(
    authorization: str = Header(None),  # ← header参数
    body: PayRequest = Body(...)
):
    # Step 1: Auth FIRST
    if not authorization:
        raise HTTPException(401, "Missing token")
    
    try:
        user = get_current_user(authorization)
    except:
        raise HTTPException(401, "Invalid token")
    
    # Step 2: Body validation AFTER
    if body.dance_id not in VALID_DANCES:
        raise HTTPException(422, "Invalid dance")
    
    # ... rest code
```

## 📝 使用方式

### 第一次改造时
1. 按 P0 顺序从上到下改（#1-5）
2. 改完一个就验收一个（用给的验收命令）
3. Day 1 再改 P1 项（#6-9）
4. Day 2-3 改功能入口（#10-12）

### 遇到问题时
- 每个改法都有 `验收` 部分，run命令检查
- 如果验收失败，说明改错了，重新看改法部分

### 大约需要多长时间
- P0 × 5项：4小时（含测试）
- P1 × 4项：4小时
- P2 × 3项：6小时
- **总计**: 14小时（1.75个工作日）
