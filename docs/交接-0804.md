## 四、API 路由速查

### 核心拆解
```
POST /api/decompose          上传任意视频 → 自动拆解（WJ_FREE_MODE=1 免费）
GET  /api/decompose/{id}     拉拆解结果（phrases/story/memory/coach）
POST /api/decompose/{id}/run 重跑（已付费或免费模式）
GET  /api/clip/{full|pN}     视频片段
GET  /api/frame/{pN}         帧图
```

### AI 比对点评（新）
```
POST /api/solo/review        上传 my_video + standard_id → 创建 review_id
POST /api/solo/review/{id}/run  触发比对（WJ_FREE_MODE=1 直接跑）
GET  /api/solo/review/{id}   拉结果
GET  /api/solo/review/{id}/clip/{seg}  问题片段视频
GET  /api/solo/review/{id}/frame/{seg} 对比帧图
```

### 其他
```
GET  /api/teachers           已拆舞蹈列表（前端选参考舞用）
GET  /api/public/stats       公开：已拆解数量（首页统计用）
GET  /api/health             服务健康检查
POST /api/auth/register      注册
POST /api/auth/login         登录
```
