## 四、首发推荐

### 推荐首发：Variant D

**理由：**

1. **标题即价值主张**："AI量出我左臂差102°，练了3次评分从63→82" — 这是一个完整用户故事，用户进来3秒能判断"这是给我的"且"我能得到具体结果"。

2. **最适配主力引流渠道**：小红书的核心传播逻辑是"真实用户真实改变"，D 的叙事方式与小红书种草内容高度同构，用户从内容到落地页没有认知跳跃。

3. **高可信度**：SVG 角度对比（你的42° vs 标准144°）+ 评价附带数据标签（71→89分），属于"展示证明"不是"声称证明"，信任成本低。

4. **无灰色地带**：没有假倒计时、假名额、假限时，合规且可长期跑。

5. **CTA 个性化**："测一测我的舞" 比"免费试试"更有行动感。

## 五、A/B 测试建议

### 第一轮：D vs B（对比核心打法差异）

**原因：**
- D = 结果叙事型（用户看到"我能变成什么样"）
- B = 价格锚点型（用户看到"我能省多少钱"）
- 这两种心理机制几乎互斥，测出哪个对舞镜用户更有效，后续所有变体都能从结论中获益

**测试周期：** 7–14天，每端至少200 UV 才有统计意义

**核心指标：**
1. 主 CTA 点击率（hero CTA CTR）
2. 首屏→付费转化率（最终结果指标）
3. 滚动深度分布（看哪个变体用户停留更久）

**胜出条件：** 主 CTA CTR 差异 ≥ 15% 或付费转化率差异 ≥ 10%，统计显著后进入第二轮

**第二轮（优化迭代）：**
- 胜出者 + C（免费钩子，但去掉假倒计时后重新跑）
- 或胜出者 + E（改为 C 端受众定位后的重跑版本）

### 流量分配建议
- 小红书引流：50% D / 50% B
- TikTok 引流：如跑 TikTok 短视频带链，建议直接用 B（价格对比 hook 天然适配短视频底部 CTA 文案）
- 自然搜索/老师渠道：直接用 E（不用拆解，直接给搜索老师关键词的用户）

## 六、共同待修项（所有变体）

1. **微信/电话占位符必须填真实信息才能上线**：所有5个变体均有 `[微信号占位]` / `[手机号占位]`，影响信任度和转化
2. **PostHog key 需替换为真实 key**：目前全部 `phc_REPLACE_WITH_REAL_KEY`，数据无法回传
3. **ICP 备案号占位**：合规要求，上线必填
4. **用户数字偏小**："已有24支拆解" / "200+舞者" — 建议达到500+用户后才开跑 A/B（小数字会降低社交证明效果）
