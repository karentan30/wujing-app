## 三、技术栈

- **后端**：Python 3.10 + FastAPI + uvicorn，SQLite（`wujing.db`，11张表），单进程
- **前端**：原生 HTML/CSS/JS 单文件 SPA（无框架、无构建、无 npm）
- **姿态引擎**：MediaPipe（独立 venv 子进程，`_live/auto_decompose.py` 调用）
- **AI 内容生成**：ARK（豆包）Vision + DeepSeek（key 在服务器 start.sh）
- **埋点**：PostHog
- **部署**：systemd `wujing-api` + Caddy（自动HTTPS），HK 服务器 47.242.80.65

## 四、本地跑起来

```bash
cd ~/projects/舞镜/_live
python3 -m venv venv && source venv/bin/activate
pip install fastapi uvicorn python-multipart requests
# 环境变量参考服务器 /www/wujing-api/start.sh
python -m uvicorn server:app --port 3006
```

注意：
- 本地测试想不碰生产数据 → 设 `WUJING_BASE_DIR=/tmp/wujing-local`（server.py 已支持）
- 拆解引擎需要 MediaPipe venv（服务器 `/www/wujing-api/mpvenv/`）和 ARK/DeepSeek key
- 支付需要商户号 key（见五），本地无 key 时支付接口返回 503 不崩
