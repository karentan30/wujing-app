# PRD · 舞镜带货(穿搭同款 · 淘宝联盟)

> 一句话:用户上传舞蹈 → AI 认出整套穿搭(演出服/妆容/头饰配饰)→ 淘宝联盟找同款+比价 → 一键买(赚佣金)。零囤货,淘宝管发货。

日期: 2026-09-07 · 状态: 上游已建,下游待淘宝联盟PID

## 1. 四层闭环
1. **认穿搭(✅已建)**:`auto_decompose._vision_outfit` 豆包看关键帧 → `{costume, makeup, accessory, keywords[]}`。已跑通(实测:"粉白渐变古典舞演出服·绸带水袖" + 淘宝关键词5个)。与拆解并发,不加墙钟。挂在 decompose 结果 `outfit` 字段。
2. **找同款(待PID)**:用 keywords 调**淘宝联盟API**(阿里妈妈物料搜索/高佣转链)→ 同款/相似款商品列表 + 价格,**排序突出最低价**。
3. **一键买(待PID)**:商品带**推广链接(含PID)**,用户点击去淘宝下单,成交按PID返佣。淘宝管库存/发货/退换=零运营负担。
4. **收款**:纯带货走淘宝返佣(无需中台);若日后做自营SKU再走 Lumee 中台(已通)。
